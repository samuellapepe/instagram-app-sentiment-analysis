# **Sentiment Analysis of Instagram App Reviews using Support Vector Machine**

Proyek ini merupakan proyek analisis sentimen terhadap ulasan pengguna aplikasi Instagram. Tujuan dari proyek ini adalah menghkasifikasikan ulasan sebagai positif, negatif, atau netral menggunakan teknik *Natural Language Processing* (NLP) dan pembelajaran mesin (*machine learning*). 

## 📁 **Dataset**
Dataset yang digunakan adalah dataset ulasan aplikasi Instagram, berisi ulasan pengguna dan label sentimen. Dataset dapat diunduh [disini.](https://drive.google.com/file/d/1iJT-6b5QDPEajP7B0U-bN3gLO8PFJKHy/view?usp=sharing)

## 🛠️ **Tools & Library**
* Python
* Pandas, NumPy
* Matplotlib, Seaborn, WordCloud
* NLTK (stopwords, tokenisasi, stemming)
* Scikit-learn (SVM, TF-IDF, evaluasi model)

## 🤖 **Model yang Digunakan**
* Model: Support Vector Machine (SVM)
* Ekstraksi fitur: TfidfVectorizer
* Metrik Evaluasi: Akurasi, Confusion Matrix, Classification Report

## 📈 **Hasil**
* Distribusi visual dari label sentimen
* Word cloud dari kata-kata yang sering muncul
* Laporan performa model klasifikasi
